# Definition of Done

Uma entrega funcional somente está concluída quando cada item estiver atendido ou marcado `NÃO APLICÁVEL` com justificativa:

- [ ] SPEC criada ou atualizada e critérios de aceite mapeados.
- [ ] ADR criada quando necessária.
- [ ] Linha de base registrada e teste RED demonstrado.
- [ ] Implementação mínima concluída.
- [ ] Testes direcionados e suíte completa aprovados ou falhas preexistentes separadas.
- [ ] Lint e type checking executados quando aplicáveis.
- [ ] Segurança e documentação revisadas.
- [ ] Diff revisado de forma independente e sem alterações fora do escopo.
- [ ] Rollback documentado quando necessário.
- [ ] Evidências apresentadas e pendências declaradas.
- [ ] Produção não executada sem autorização.
